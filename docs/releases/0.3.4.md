# Aion2Pulse 0.3.4

Compact overlays and clearer encounter history make the meter easier to use during play. This release brings the tested UI and tracking improvements from the preview branch into the regular Windows package.

- Tighter player and value columns across Raid Classic, Focus Glass and Combat Studio; automatic width and saved manual resizing.
- Cleaner footer and title shortcuts for metric, design and tracking mode.
- Separate pulls, configurable combat chains and manual reset modes.
- Sliders for interface scale, player row height and surface intensity.
- Independent retention of 50 known boss fights and 50 normal pulls, with resizable history details.
- Skill-effect timelines, selectable DPS/HPS graph ranges, counterpart filters, incoming incident review and comparable boss attempts.
- Contextual tooltips throughout the overlay, settings, history and analysis; latency source and sample age in the ping tooltip.
- Updated README and actual application screenshots using synthetic data.

## Data coverage

Timelines show observed effects, not verified cast starts. State-based analysis depends on packet coverage; missing data remains unknown. Party/boss edge cases and individual flag meanings still need further Global-client validation. The diagnostic recorder, experimental periodic-healing interpretation and planned Kina counter remain on the separate research branch and are not included.

## Download and update

Download **Aion2Pulse-win-x64.zip**, extract the complete archive and launch **Aion2Pulse.exe** as administrator. Keep your existing `history/` folder and `settings.json` when updating. The package includes the .NET runtime and WinDivert.

## Validation

Release build with zero warnings/errors and 1,296 passing automated tests; synthetic UI screenshots reviewed; packaged executable version and archive privacy checks verified. Automated checks do not establish full live party coverage.
